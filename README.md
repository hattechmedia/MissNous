# MissNous Monorepo

This repository contains the full MissNous project structure:

- **`Admin/`**: Admin dashboard frontend (React + Vite)
- **`backend/`**: Node.js / Express REST API backend (MongoDB)
- **`MissNous/`**: Customer-facing eCommerce website frontend (React + Vite)

## Getting Started

### Backend
```bash
cd backend
npm install
# Configure .env file from .env.example
npm start
```

### Admin Panel
```bash
cd Admin
npm install
npm run dev
```

### Main Website
```bash
cd MissNous
npm install
npm run dev
```
